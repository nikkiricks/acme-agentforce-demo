Where the numbers live

Provenance for every figure on the board — the transparency is the talking point

The one live number — 25

The "+25 live in this workspace · LIVE FROM CRM" badge is a real-time SOQL count of Contact records in the org — the same roster the Agentforce agent screens (17 imported candidates + 8 pre-existing contacts). It runs WITH USER_MODE, so it only counts what the viewer's own access allows.

SELECT COUNT(Id) FROM Contact WHERE Email LIKE '%example.com'

See the records: App Launcher → Contacts, or sf org open -p "/lightning/o/Contact/list", or the repo's canonical check, bash scripts/verify-roster.sh.
